The first public version of Upstart: build websites by talking to an agent, on your own computer. Free, MIT licensed, no account.

## Download

- **macOS** (Apple silicon, macOS 13 or later): `Upstart-0.2.0-arm64.dmg`. Open it and drag Upstart to Applications.
- **Windows** (x64), **beta**: `Upstart-Setup-0.2.0-x64.exe`. It is not signed yet, so Windows SmartScreen warns of an unknown publisher at the first launch: choose "More info", then "Run anyway". Upstart needs [Git for Windows](https://git-scm.com/downloads/win), which gives the agent its shell; it asks for it at the first launch.

Upstart updates itself from now on.

## What it does

- Describe a website, or start from one of 24 templates, and the agent builds it while you watch the page take shape.
- Claude, with your Claude subscription or an API key; or ChatGPT, OpenAI, Gemini and Vertex AI models.
- Edit by hand in the page, comment on its elements, undo any change.
- Content in collections and lists, a media library, forms whose answers stay in your website.
- Themes with contrast warnings and open fonts; nearly two hundred ready-made sections.
- Export as a static site, a Node app or a Cloudflare Worker, with a guide to putting it online.

## Known limits

- Windows is a beta: there the agent's commands are not confined by a sandbox; auto mode judges each risky one.
- No Linux build yet.
- The interface is in English.
